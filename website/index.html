About the Project

Automated cloud deployment using AWS SDK

This project automates the deployment of a static HTML website to Amazon S3 using Python and boto3. Instead of manually uploading website files through the AWS Console, a Python script performs the deployment automatically.


The script can create or check an S3 bucket, upload website files, configure static website hosting, and provide the public website endpoint.

Deployment Process

Automated deployment workflow

1

Install Requirements

Install Python and boto3 on the local machine.

2

Create or Check S3 Bucket

Python checks whether the bucket exists and creates it if required.

3

Upload Website Files

HTML, CSS, JavaScript and other website files are uploaded automatically.

4

Configure Static Website Hosting

S3 static website hosting is enabled and index.html is configured.

5

Get Website Endpoint

The Python script displays the S3 website URL for browser access.
